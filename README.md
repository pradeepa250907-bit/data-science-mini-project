# 📊 Module 05 – Real-World Data Analysis

## Student Performance Analysis Using Python

### 📌 Project Overview

This project explores a real-world Student Performance dataset to understand the factors associated with students' academic outcomes.

Using Python, I performed Exploratory Data Analysis (EDA), examined statistical relationships, and created visualizations to transform raw educational data into meaningful insights.

The project is part of my hands-on Data Analytics learning journey.

## 🎯 Project Objectives

- Explore a real-world dataset from a public source.
- Perform data cleaning and preprocessing.
- Analyze patterns, trends, and relationships.
- Create meaningful data visualizations.
- Summarize findings using Jupyter Notebook.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📂 Dataset Information

**Dataset:** Student Performance Dataset  
**Source:** UCI Machine Learning Repository  
**Records:** 395  
**Attributes:** 33

Dataset Link: https://archive.ics.uci.edu/dataset/320/student+performance

The dataset contains information about students' study habits, attendance, previous academic performance, and other educational factors.

## 📈 Visualizations Created

1. **Histogram:** Distribution of students' final grades.
2. **Bar Chart:** Study time vs average academic performance.
3. **Scatter Plot:** Relationship between absences and final grades.
4. **Box Plot:** Comparison of final grade distributions by gender.
5. **Correlation Heatmap:** Relationships between numerical variables.
